管理者向け操作マニュアル

1. システム概要

WEB請求書システムは、請求書PDFファイルをオンラインで管理・配信するためのシステムです。

主な機能

  • 文書管理: 請求書PDFの登録・検索・ダウンロード
  • 取引先管理: 取引先情報とグループの管理
  • 新規登録承認: 取引先からの新規登録依頼の承認
  • 変更依頼承認: 担当者変更依頼の承認
  • PDF暗号化: グループパスワードによる自動暗号化
  • API連携: 請求書発行システムからの自動登録
  • メール通知: 文書登録時の自動通知

ユーザー種別

ユーザー種別 説明 権限
管理者（staff） システム管理者・事務担当者 全機能の利用、承認・管理操作
取引先（client） 取引先の担当者 自社の文書閲覧・ダウンロード、プロフィール編集
APIユーザー（api） 請求書発行システム API経由での文書登録のみ

2. ログイン

ログイン手順

  1. ブラウザでシステムのURLにアクセス
    http://your-domain.com/login/
  2. メールアドレスとパスワードを入力
  3. 「ログイン」ボタンをクリック
初期アカウント
メール: staff@example.com
パスワード: staff123
※初回ログイン後、必ずパスワードを変更してください

パスワードを忘れた場合

Django管理画面からパスワードをリセットできます。

  1. 管理画面にアクセス: http://your-domain.com/admin/
  2. 「ユーザー」→ 該当ユーザーを選択
  3. 「このフォーム」セクションで新しいパスワードを設定

3. ダッシュボード

ログイン後、スタッフダッシュボード画面が表示されます。

ダッシュボードの機能

  • 新規登録依頼（未承認）: 承認待ちの新規登録依頼一覧
  • 変更依頼（未承認）: 承認待ちの変更依頼一覧
  • クイックアクション: 各機能への素早いアクセス
    • 取引先一覧
    • 文書検索
    • 文書アップロード
    • 管理画面
注意
未承認の依頼は速やかに対応してください。依頼者は承認されるまでシステムを利用できません。

4. 新規登録依頼管理

新規登録依頼の承認手順

  1. ダッシュボードから「新規登録依頼（未承認）」の「詳細」ボタンをクリック
  2. 依頼内容を確認
    • 取引先コード（5桁）
    • 取引先名
    • 郵便番号・住所
    • 電話番号・FAX番号
    • 代表メールアドレス
    • グループパスワード
    • 担当者情報（氏名、メール、パスワード）
  3. 内容に問題がなければ「承認」ボタンをクリック
  4. 確認ダイアログで「OK」をクリック

承認時の自動処理

  • 取引先マスタの作成
  • グループの作成
  • グループメンバー（担当者）の作成
  • ログイン用ユーザーアカウントの作成
  • 承認完了メールの送信

却下する場合

  1. 依頼詳細画面で「却下」ボタンをクリック
  2. 却下理由を入力
  3. 「却下する」ボタンをクリック
  4. 却下通知メールが申請者に送信されます
ヒント
取引先コードは既存の取引先と重複しないように注意してください。

5. 変更依頼管理

変更依頼の種類

  • 担当者の追加
  • 担当者の削除
  • 担当者情報の変更（氏名、メールアドレス）

変更依頼の承認手順

  1. ダッシュボードから「変更依頼（未承認）」の「詳細」ボタンをクリック
  2. 変更内容を確認
  3. 問題なければ「承認」ボタンをクリック
  4. 変更が適用され、申請者にメール通知されます

却下する場合

  1. 変更依頼詳細画面で「却下」ボタンをクリック
  2. 却下理由を入力
  3. 「却下する」ボタンをクリック

6. 取引先管理

取引先一覧の表示

  1. ダッシュボードから「取引先一覧」をクリック
  2. 登録されている全取引先が表示されます

取引先詳細の確認

  1. 取引先一覧から「詳細」ボタンをクリック
  2. 以下の情報が表示されます
    • 基本情報（コード、名称、住所、連絡先）
    • グループ情報（グループパスワード）
    • 担当者一覧（氏名、メール、ログイン状態）

取引先の文書検索

取引先詳細画面から「文書を検索」ボタンをクリックすると、その取引先の文書のみを検索できます。

重要
グループパスワードは文書の暗号化に使用されます。変更すると、既存の暗号化文書が開けなくなる可能性があります。

7. 文書管理

文書検索

  1. ダッシュボードから「文書検索」をクリック
  2. 検索条件を入力
    • 取引先コード: 空欄の場合は全件検索
    • 年度: 例：2024
    • 月: 例：12
  3. 「検索」ボタンをクリック

検索パターン例

取引先コード 年度 月 結果
（空欄） （空欄） （空欄） 全文書を表示
00001 （空欄） （空欄） 取引先00001の全文書
（空欄） 2024 （空欄） 2024年の全文書
00001 2024 12 取引先00001の2024年12月の文書

文書詳細の確認

  1. 検索結果から「詳細」をクリック
  2. 文書情報が表示されます
    • ファイル名
    • 文書種別（月次/随時）
    • 請求書番号
    • 請求日
    • 版数
    • ファイルサイズ
    • 暗号化フラグ
    • アップロード日時・ユーザー

文書のダウンロード

  1. 文書詳細画面または検索結果から「ダウンロード」をクリック
  2. PDFファイルがダウンロードされます
  3. 暗号化されている場合、グループパスワードの入力が必要です

文書の削除

  1. 文書詳細画面で「削除」ボタンをクリック
  2. 確認ダイアログで「OK」をクリック
  3. 注意: 同じファイル名の全ての版が削除されます
警告
削除した文書は復元できません。削除前に必ず確認してください。

8. 文書アップロード

アップロード手順

  1. ダッシュボードまたは文書検索画面から「文書アップロード」をクリック
  2. 文書情報を入力
    • 取引先コード: 5桁の数字（必須）
    • 文書種別: 月次請求書 or 随時請求書（必須）
    • 請求書番号: 例：INV-00001-202412-001（必須）
    • 請求日: カレンダーから選択（必須）
    • PDFファイル: 最大20MB（必須）
    • 暗号化する: チェックするとグループパスワードで暗号化
  3. 「アップロード」ボタンをクリック
  4. 確認ダイアログで「OK」をクリック

自動処理

  • フォルダ自動作成: 取引先コード → 年度 → 月 の階層構造
  • 版数管理: 同じファイル名の場合、版数が自動的にインクリメント
  • 暗号化: チェックONの場合、グループパスワードで暗号化
  • メール通知: 取引先の全担当者にメール送信

注意事項

  • ファイルサイズは20MB以下
  • PDFファイルのみアップロード可能
  • 取引先コードは事前に登録されている必要があります
  • 同じファイル名でアップロードすると新版として登録されます
  • 暗号化にはグループパスワードが必要です
ヒント
暗号化された文書は、取引先のグループパスワードを使用して開けます。

9. API連携

APIユーザーの作成

  1. Django管理画面にアクセス: http://your-domain.com/admin/
  2. 「ユーザー」→「ユーザーを追加」をクリック
  3. 以下の情報を入力
    • メールアドレス: api@yourcompany.com
    • 氏名: 請求書発行システム
    • ユーザー種別: api
    • 有効: チェックON
  4. パスワードを設定
  5. 「保存」をクリック

API利用手順書

詳細な利用手順は API_USAGE.md を参照してください。

APIエンドポイント

エンドポイント メソッド 説明
/api/login/ POST APIログイン
/api/logout/ POST APIログアウト
/api/documents/upload/ POST 文書アップロード

10. Django管理画面

アクセス方法

  1. ダッシュボードから「管理画面」をクリック
  2. または直接 http://your-domain.com/admin/ にアクセス

管理画面でできること

  • ユーザー管理: ユーザーの追加・編集・削除、パスワードリセット
  • 取引先管理: 取引先情報の直接編集
  • グループ管理: グループパスワードの変更
  • 文書管理: 文書の直接編集・削除
  • フォルダ管理: フォルダ構造の確認・編集
警告
管理画面での直接編集は慎重に行ってください。誤った操作はシステムの動作に影響を与える可能性があります。

11. トラブルシューティング

よくある問題と解決方法

Q1: ログインできない
  • メールアドレスとパスワードが正しいか確認
  • ユーザーが有効化されているか確認（管理画面で確認）
  • ユーザー種別が「staff」になっているか確認
Q2: 文書がアップロードできない
  • ファイルサイズが20MB以下か確認
  • ファイル形式がPDFか確認
  • 取引先コードが正しいか確認
  • 暗号化ONの場合、グループパスワードが設定されているか確認
Q3: PDFが暗号化されない
  • 「暗号化する」にチェックが入っているか確認
  • 取引先のグループパスワードが設定されているか確認
  • エラーメッセージを確認
Q4: メール通知が届かない
  • メールサーバーの設定を確認（settings.py）
  • 受信者のメールアドレスが正しいか確認
  • 迷惑メールフォルダを確認
Q5: 検索しても文書が表示されない
  • 検索条件が正しいか確認
  • 全件検索（全項目空欄）で確認
  • 文書が実際に登録されているか管理画面で確認

サポート

上記で解決しない場合は、システム管理者に問い合わせてください。
